# Пульт Телекарта EVO 09

Android-приложение: пульт для спутниковой приставки **Телекарта EVO 09 HD** (родной пульт HD04 / RC-EVO09) через ИК-порт телефона. Сделано под Redmi Note 8, подойдёт любой Android 5+ с ИК-передатчиком (Xiaomi, Redmi, POCO, часть Huawei и Honor).

## Установка

1. Открой вкладку **Releases** этого репозитория (или **Actions → Build APK → последняя сборка**).
2. Скачай `pult-telekarta.apk` на телефон и открой. Разреши установку из этого источника.

## Почему нужен подбор

Кодов EVO 09 нет в открытых базах (Mi Remote, IRDB, LIRC), поэтому их не найти в списке устройств «Mi Пульта». Redmi Note 8 умеет только **передавать** ИК, а принять сигнал с родного пульта не может. Поэтому коды подбираются перебором, приставка показывает, когда код подошёл.

Почти все китайские спутниковые ресиверы работают по протоколу **NEC** (38 кГц): адрес устройства плюс номер команды 0x00–0xFF. Найти нужно один адрес и номер команды для каждой кнопки.

## Как настроить (≈15–20 минут один раз)

1. Включи приставку и телевизор. Направь верхний торец телефона на приставку с 1–3 м.
2. **⚙ Настройка → «1. Найти адрес» → Старт.** На каждый адрес уходят все 256 команд (≈40 с). Начинается с самых частых адресов (0x00, 0x01, 0x02…). Как только приставка что-то сделает (переключит канал, откроет меню, выключится), жми **«✋ Сработало!»**. Адрес сохранится.
3. **«2. Подбор команд» → Старт.** Команды идут по одной (скорость выбирается). Увидел реакцию: **«Сработало!»**. Ниже появится список последних отправленных команд: нажимай на строки, чтобы повторить и понять, какая именно сработала. Затем **«✔ Назначить команду … кнопке»** и выбери, что это была за кнопка.
4. Пройди все 256 команд: так найдутся почти все кнопки за один проход (≈5 минут на средней скорости).
5. На главном экране серые кнопки ещё не настроены. Нажми на такую кнопку, и откроется подбор именно для неё.

Если в режиме адреса прошли все 256 адресов без реакции, включи протокол **Samsung** и повтори. Ещё проверь, что ИК работает: камера другого телефона видит мигание ИК-диода.

Перебор может открыть меню или переключить канал, это нормально. Потом нажми «Выход». Настройки приставки защищены PIN-кодом, но на всякий случай перебирай без активных меню сброса.

## Поделиться кодами

**Настройка → Экспорт** даёт текст вида

```
protocol=NEC
address=0x00
power=0x0A
ok=0x1F
...
```

Его можно сохранить или отправить человеку с такой же приставкой, а он нажмёт **Импорт**. Если пришлёшь этот текст мне, я вшью коды в приложение по умолчанию.

## Сборка

GitHub Actions (`.github/workflows/build-apk.yml`) на каждый push запускает тесты, собирает debug-APK и публикует его в Releases. Локально: `gradle assembleDebug` (нужны JDK 17 и Android SDK 34).

Код: `app/src/main/java/kz/teamcargo/pult/`
- `IrCodec` — паттерны NEC/Samsung (покрыт тестами)
- `MainActivity` — сам пульт
- `SetupActivity` — поиск адреса и подбор команд
- `Config` — хранение кодов, экспорт и импорт
